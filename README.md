# Pixel Island (Dynamic Island dla Pixela 10a)

Budowanie APK:
- GitHub: wrzuć ten folder do nowego repo -> zakładka Actions -> "Build APK" -> Run workflow -> pobierz artefakt PixelIsland-apk (app-debug.apk).
- albo Android Studio: File > Open > ten folder > Build > Build APK(s).

Na telefonie: zainstaluj APK, otwórz "Pixel Island" i wykonaj kroki 1-4 z ekranu.
